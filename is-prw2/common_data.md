# Набір спільних даних

У завданнях 2 і 3 використовується невеликий штучний простір кандидатів. Обидва паролі індивідуального варіанта мають формат:

```
password = <base_word> + <two_digit_number>
```

| Група | Дозволені основи паролів |
| :-: | - |
| 1 | alpha, amber, atlas, binary, birch, bridge, cobalt, comet, delta |
| 2 | eagle, ember, falcon, forest, galaxy, harbor, hazel, island, kernel |
| 3 | laser, maple, matrix, meteor, neon, ocean, orbit, panda, pixel |
| 4 | quartz, river, rocket, silver, signal, solar, tiger, vector, violet |
